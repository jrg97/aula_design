# Calculadora de Média #
Calculo de média de duas notas de alunos

## Tecnologias Utilizadas ##
Python 3.13

## Como instalar e executar ##
Pode ser executado em qualquer máquina que tenha Python instalado.

## Exemplo de uso ou demonstração ##
Resultado no console de um aluno que teve as notas 9 e 8.  
=== Sistema de Notas do Aluno ===  
Digite a primeira nota: 9  
Digite a segunda nota: 8  
A média final é: 8.50
